# Complice - prototype

Site statique : un seul fichier `index.html`, sans installation ni serveur.

## Mettre en ligne sur GitHub Pages (gratuit)
1. Crée un compte sur github.com, puis un nouveau dépôt (par exemple `complice`).
2. Clique sur "Add file" puis "Upload files" et glisse tout le contenu de ce dossier.
3. Valide avec "Commit changes".
4. Va dans Settings, puis Pages. Choisis la branche `main` et le dossier `/ (root)`, puis enregistre.
5. Après une ou deux minutes, le site est disponible sur `https://TON-PSEUDO.github.io/complice/`.

## Autres options gratuites
Netlify, Cloudflare Pages ou Vercel : tu glisses le dossier, ils te donnent un lien.

## Avant de partager le lien publiquement
- Les textes juridiques de l'appli sont des brouillons : fais-les relire.
- Hors de Claude, le compte est gardé dans le navigateur de chaque visiteur (pas de vrai compte partagé).
